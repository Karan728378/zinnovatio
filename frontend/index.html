Parali Mitra Architecture, Shared Contract & Team Roles

Zinnovatio 4.0 Hackathon Specification (Zinnovatio 4.0, Chandigarh University)

Honesty & Groundedness Rules

  • Rule-Based Core + Validated ML: Transparent formulas for statutory co-firing and auditable receipts; trained random forest for biomass yield forecasting.
  • Real Fire Data: NASA FIRMS active fire detections mapped to 0.05° (~5 km) grid cells as a relative supply index.
  • Fire Undercount Reality: Over 90% of fires occur after 3 PM outside satellite pass; hence index represents density, not absolute tonnage (iFOREST 2025).
  • Sample Data Labeling: Kilns, suppliers, deliveries, and prices clearly labeled as sample data in the prototype.

Team CrackHeads Responsibilities

Person 1: Lead, Repo, FastAPI backend, SQLite, Integration
Person 2: Fire data pipeline, supply map file, mathematical formulas
Person 3: Supplier app (farmer/aggregator), i18n English/Hindi
Person 4: Kiln calculator page + Regulator dashboard + Leaflet map
Person 5: Sample data CSVs, sources list, pitch deck, test log, video
