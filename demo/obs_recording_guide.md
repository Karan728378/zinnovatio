# Parali Mitra - 2-Minute OBS Backup Video Checklist (Task 7 - Post-Freeze H16)

1. Open OBS Studio -> Add Source -> Window Capture (Chrome) + Audio Input Capture (Mic).
2. Settings -> Output -> Recording Format: MP4, 1920x1080, 30 fps.
3. Follow docs/demo_script.md (Steps 1 to 6) in strictly under 2 minutes (120 seconds).
4. Save output file as: demo/Parali_Mitra_Backup_Demo.mp4
5. Save copies in 3 required places:
   - Place 1: This repo (demo/ folder) or Google Drive
   - Place 2: Physical USB pen drive
   - Place 3: Desktop of the presenting laptop
