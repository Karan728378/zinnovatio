> **Rule**: If your code and this document disagree, this document wins. To change it, tell Person 1, who updates it and informs everyone.

## 1. Files and Columns
| File | Generated By | Exact Columns |
|---|---|---|
| `data/seed/kilns.csv` | Person 5 | `kiln_id,name,lat,lon,village,monthly_fuel_tonnes` |
| `data/seed/suppliers.csv` | Person 5 | `supplier_id,name,kind,lat,lon,village,straw_form,price_per_tonne,available_tonnes` |
| `data/seed/deliveries.csv` | Person 5 | `delivery_id,kiln_id,supplier_id,date,tonnes,form,photo_ref` |
| `data/processed/supply_cells.csv` | Person 2 | `cell_id,lat,lon,fire_count_last_season,supply_index` |
| `data/processed/config.json` | Person 2 (with P1) | Demo month, map centre/zoom, mandate schedule, cost settings |

- Values: `kind = farmer | aggregator | pellet_unit`
- `straw_form` and `form = bale | chopped | pellet`
- Identifiers: `K001` kilns, `S001` suppliers, `D001` deliveries, `CELL_001` cells.
- Dates: `YYYY-MM-DD`. All sample rows say "Sample" in the name.

## 3. API Endpoints
| Method | Path | Purpose |
|---|---|---|
| `GET` | `/health` | API operational status |
| `GET` | `/config` | Platform runtime settings |
| `GET` | `/supply/map` | Fire density / supply cells for map overlay |
| `GET` | `/kilns` | List of monitored brick kilns |
| `GET` | `/kilns/{kiln_id}/needs?month=` | Kiln straw tonnes needed, delivered so far, and compliance gap |
| `GET` | `/kilns/{kiln_id}/suppliers` | Ranked nearest suppliers with delivered cost vs coal |
| `POST` | `/listings` | Supplier creates straw listing; returns nearest kilns |
| `GET` | `/suppliers/{supplier_id}/kilns` | Nearest kilns for a supplier |
| `POST` | `/deliveries` | Record a straw delivery; returns receipt ID |
| `GET` | `/compliance/summary?month=` | All kilns vs mandate target, for regulator dashboard |

## 4. Mathematical Formulas
1. **Straw Needed (tonnes)**:
   $$\text{straw\_needed} = \text{mandated\_share} \times \text{monthly\_fuel\_tonnes} \times \text{straw\_to\_fuel\_factor}$$
2. **Delivered Cost per Tonne**:
   $$\text{delivered\_cost} = \text{price\_per\_tonne} + (\text{transport\_rate} \times \text{distance\_km}) + (\text{chopping\_cost if form is chopped})$$
3. **Compliance Share**:
   $$\text{compliance\_share} = \frac{\text{straw\_delivered\_in\_month}}{\text{monthly\_fuel\_tonnes}}$$
   Status is `meets_target` if `compliance_share >= mandate_share`, else `below_target`.
4. **Supply Index**:
   $$\text{supply\_index} = \frac{\text{fire\_count\_in\_cell}}{\max(\text{fire\_count})}$$
5. **Distance**: Great-circle distance in kilometres using the Haversine formula ($R = 6371.0\text{ km}$).
